# Privacy and Data Handling

This repository is packaged for portfolio use.

Excluded from the public demo:
- production drama video files
- supplier-delivered media
- private character asset documents
- API credentials
- private evaluation notes containing proprietary content

The public `portfolio_demo.py` uses synthetic evidence. The full `app.py` processes user-uploaded media during the running Streamlit session and sends required evidence to configured model APIs as part of the QA workflow.

Before using the full app with production content, verify that your organization permits the selected API/provider and data-handling setup.
